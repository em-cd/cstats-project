# Predicting House Sale Prices with Statistical Modeling and Neural Networks
Computational Statistics Course - Université de Neuchâtel


The goal of this project is to predict residential house sale prices in Ames, Iowa using a pipeline of statistical and machine learning methods. Using the Kaggle dataset [House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data), we build and compare several modelling techniques from 

The training dataset contains 1,460 training observations with 81 columns (79 explanatory variables plus Id and SalePrice) describing structural, qualitative, and locational characteristics of residential properties. The test dataset contains 1,459 observations for which final sale price predictions are generated.

The final predictions produced by the neural network are stored in `submission.csv`.

## Project Structure

The project is divided into five main parts:

### 1. Classical Statistical Inference

Exploratory statistical analysis and inference on selected variables from the dataset, including descriptive statistics and hypothesis testing.


### 2. ANOVA Analysis

Analysis of variance (ANOVA) conducted on selected categorical features to evaluate their influence on house sale prices.


### 3. 2^3 Factorial Design

A factorial experiment performed on a subset of selected features to study interaction effects between variables.


### 4. Parametric Regression

Construction and evaluation of ordinary least squares (OLS), Ridge, and Lasso regression models for house price prediction.

### 5. Neural Network

Development of a neural network trained on the full dataset to improve predictive performance and generate final Kaggle submission.
